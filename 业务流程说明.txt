================================================================
 小莉客服系统 业务流程说明
 更新：2026-09-28（09-23 全代码核对版基础上修订）
================================================================

一、主链路（客户视角）
  加微信 → 问"你好，是哪位" → 客户回复 → 自动分类
  → 打标签（微信+数据库） → 推首次业务介绍 → 知识库交流
  → 答不上/人工介入 → 管理员跟进 → 继续知识库交流（循环）

二、各环节说明

  1. 新好友
     自动通过 → 只发一句 greeting（"你好，是哪位"）→ 等回复
     非好友拦截（2026-09-28）：好友请求未通过（含风控拦截未通过成功）前，
       对方发来的私聊消息一律忽略——不回应、不打标签、不入库、不进流程；
       通过好友后立即恢复正常（自动通过成功或人工在手机上通过均生效）
       判定依据：好友通过事件 → 历史建档 → 微信协议好友关系查询

  2. 自动分类（未打标签客户，判断期小莉沉默）
     关键词层：每句即判，命中立即归类（渠道注册顺序=优先级）
     LLM 层：每攒 3 句未命中，交 LLM 软分类（输入带最近 5 个来回，
             含人工客服的回复——人工回复会自动以 human_ 标记入库）
     unknow：沉默不回 + 管理群只通知一次（附最近聊天）
             后续消息继续尝试，命中即正常启动
     人工判断：手机打标签

  3. 分类命中 → 启动
     数据库打渠道标签 + 手机微信打标签（只应用已有标签，不创建）
     拉取资料落 biz_wx_userinfo（分类完成即拉）
     推首次业务介绍（每客户仅一次）：
       sdwan    = 营销图 + 价格表 + "方便拉群吗"（3条）
       zhaopin  = 官网/材料引导 + 发简历 + "我要来面试"（3条）
       football = 提问式开场"要哪个球场"（1条）
       yingxiao/huleme = 渠道关闭中（关键词已就绪，待知识库）

  4. sdwan 自动建群（等客户回应式）
     介绍+进群邀请发完后，等客户任意一个回复才建群（不回复就不拉）；
     拉群后点对点聊天暂停 5 分钟（点对点唯一一次，到期自动恢复）
     建群时：
       成员 = 客户 + 固定五人（名单在 config.json
              xiaoli.channels.sdwan.group_members，末位=lxq观察号）
       群名 = SDWAN5888 起逐群 +1（xl_counter 表持久化，盲计数：
              只按自己记的数 +1，不查存量群名、不管是否重名）
       建好 → 存通讯录 → 自动接管 → 群里按流程推营销（图+价格表）
     新服务群豁免休息窗：销售在群里发言只 silence 那一条，群聊照常
     已有任何标签的客户不再触发建群
     管理群收"已自动拉群"通知；建群接口失败回落"请人工拉群"提醒

  5. 知识库交流（已分类客户，私聊/群聊同一套 12 秒防抖合并）
     连发消息静默满 12 秒（merge_wait_seconds）后合并交 LLM，
     新消息重置计时；flush 前重查标签/开关/休息窗
     合并文本只拼内容、不带任何前缀（前缀会污染问法匹配）；
     "（X 说）"发言人行只用于管理群通知展示
     问答三级优先级：
       命中问答条目问法 → 代码级逐字原样输出该答案（不经 LLM）
       无条目有介绍事实 → LLM 用事实组织 1-2 句（混合消息只答有
       依据部分，答不上的部分忽略不提）
       完全无依据 → 答不上话术 + 记未答记录 + 推管理群
         答不上话术=😊😊😊（三个笑脸，2026-09-28 定稿，不再用测试文案）
         回完即停止该会话自动应答，私聊5分钟/群6小时到点自动恢复
     防编造：回复出现"知识库/没有相关记录/待补充"等痕迹 → 带纠正
     指令重试一次 → 仍有痕迹则回固定话术（不推管理群）
     {{{}}} 指令：对客户一律隐藏
       人工介入：… → 推管理群（时间+昵称+来话，请管理员跟进）
       发送图片：地址 → 发图（绝对/项目相对/知识库文件名）
       发送文件：文件名 → 发附件（渠道知识库内递归查找）
       未识别指令 → 仅隐藏（留扩展）
     链接不单独发卡片，随原文一次发出；超 600 字拆 2 段连发

  6. 人工介入循环
     答不上 / {{{人工介入}}} / 拉群失败提醒 → 管理员跟进
     [太阳] = 翻转该会话自动聊天开关（发一次=翻转，不管是否撤回）
       操作人=群主或销售（SDWAN群角色定义见第7节）；客户发[太阳]无效
       默认全开；发一次=关、再发一次=开；[月亮]已作废
       群里：销售从自己微信发[太阳]即翻转；机器人账号发的需撤回定位
         （自发推送不带会话信息，1小时内撤回均有效，60秒未撤回推提醒）
       按会话隔离：A/B 客户私聊、各群、群与私聊互不影响
       纯内存态：重启进程恢复默认全开；每次切换推管理群通知
       停答后到点自动恢复（2026-09-28 定稿）：私聊5分钟、群6小时
         （config.json xiaoli.private_resume_seconds=300 /
          group_resume_seconds=21600，可调；手动关停和答不上停答共用）
         恢复时推管理群【自动聊天恢复】；重复停答重新计时；手动开启即取消定时
     人工回复自动入库（human_ 前缀标记），供分类上下文判断

  7. 群聊
     群聊两条来源：sdwan 自动拉群（见第4节）/ 管理员手动建群
     （群名匹配渠道规则即接管，如 SDWAN+4位数字）
     SDWAN 服务群角色定义（2026-09-28）：
       群主 = 机器人账号（self_wxid，自动建群的群主）或任意销售
       销售 = config.json xiaoli.sales_wxids（默认 king475948167、
              xiechao；可手工增删，改完重启生效）
       客户 = 群主和销售以外的其它成员
     → 群首条消息到达即自动接管 + 主动发群营销
     → 群内客户消息自动应答；管理员发言正常回复
     主要销售（king475948167 / wxid_iantzo7ndn1j29，休息窗专用
     固定名单，独立于 sales_wxids）发言：
       普通群：该条不回 + 小莉在本群休息 5 分钟（仅入库），
       销售再发言窗口无条件顺延（有销售聊天就一直停）
       自动拉的服务群：豁免，只 silence 那一条

  7b. 管理群通知一律用昵称/群名（不发原始 wxid/群id）
     昵称先查 biz_wx_userinfo，没有则拉一次落库再取；群名同理
     管理群里的消息小莉只入库，不回复
     通知格式（2026-09-23 定稿）：
     【答不上】[sdwan] SDWAN8694群 ：\n（w897844131 说）…
     【答不上】[zhaopin] “私聊 昵称”说: …       ← 内容超200字截断加 ...
     【已自动拉群】[sdwan] “春艺琳” → 群“SDWAN5890”，已推介绍，
                    点对点聊天暂停 5 分钟，自动群聊启动

  8. sdwan 到期管理（每天 8 点）
     状态流转：未销售 → 使用中 → 准备到期(≤7天) → 已过期
     通知节点：提前7/3/2天、当天、过期1/3天（客户+管理群）
     到期日/销售状态：SQL 手工维护

  9. 每月收费提醒（每小时检查）
     到配置的几号发一条提醒给客户，发过当月不重发
     收费计划：SQL 手工维护

三、渠道与标签对照
  sdwan=13(启用)  yingxiao=18(关)  huleme=21(关)
  football=22(启用，知识库已有)  zhaopin=23(启用，知识库待写)
  一个客户只认第一个标签；开关符号（[太阳]）全渠道统一
